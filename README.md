## 📌 ¿Qué es?

Es mi portfolio personal: una página estática donde me presento como desarrollador backend junior, muestro mis habilidades y proyectos (con enlaces a sus repositorios) y enlazo a mi perfil de GitHub.

## 🛠️ Tecnologías utilizadas

- **HTML5** y **CSS3**: estructura y estilos de la página
- **Git y GitHub**: control de versiones, con commits siguiendo Conventional Commits
- **GitHub Pages**: publicación y despliegue automático
- **Visual Studio Code** con **Live Server**: desarrollo y pruebas en local
